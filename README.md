# VeeamHub Repository Template

The repository contains useful Nutanix-related scripts. First of all, scripts related to Veeam Backup for Nutanix AHV. 

The [`vbrcli_13.1`](vbrcli_13.1) folder holds `vbrcli`, a single-file dependency-free Python CLI for the Veeam Backup & Replication 13.1 hypervisor plug-ins — Nutanix AHV first, and also Proxmox VE, XenServer / XCP-ng, Scale Computing HyperCore, HPE Morpheus VM Essentials and Sangfor aSV. It is built primarily as an integration surface for AI agents, and works as a human-facing CLI too. For VBR 13.1 only.
